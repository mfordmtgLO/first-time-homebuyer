Its rendered agent cards expose an agent headshot, name, brokerage, city/state, RealTrends rank and production metrics, phone when available, email when available, Website / Bio link when available, Zillow Profile link when available, principal broker, office ranking context, and internal notes/full-profile actions.

The public client bundle uses authenticated tRPC procedures including `agents.list` and `agents.exportCsv`. A server-to-server request without the authorized browser session returned the sign-in experience, so the current dashboard must not assume it can fetch the private directory directly without a supported credential or export contract. The initial implementation should preserve source provenance, be Oregon-only, and use data the owner explicitly authorizes for import. Future automatic refresh requires an approved source API/export endpoint or credential path rather than browser-session scraping.
